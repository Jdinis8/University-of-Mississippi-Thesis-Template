# University-of-Mississippi-Thesis-Template
Non-official thesis template for University of Mississippi thesis, complying with all the official requirements. 

This template will only work with TeX Live distributions from 2025 onwards. Please install the most up-to-date version whenever possible (see [here](https://www.tug.org/texlive/quickinstall.html)).

If you want github to automatically compile the pdf on the repo, go to Actions -> Workflow Permissions -> enable "Read and write permissions".
